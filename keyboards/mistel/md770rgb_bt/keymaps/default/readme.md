# Default MD770 RGB BT keymap

QWERTY with Fn media/navigation shortcuts and Pn controls built from standard
QMK keycodes. Pn+1 selects Bluetooth; Pn+2 selects USB. Tap Pn+F1/F2/F3 to
select a Bluetooth slot, or hold for three seconds to pair. Pn+Insert enters
the updater. Pn+F5 advances the RGB effect, Pn+F9 toggles it and Pn+0 turns
lighting off. Pn+arrows adjust brightness and speed.

Use `default_mistel` for the factory DIP-switch mappings, profiles, onboard
assignments/macros, Fn/Pn relocation and per-key colour editor. Clear QMK
settings when switching between these two keymaps.
